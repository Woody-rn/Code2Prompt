# Code2Prompt

Собирает файлы проекта в txt-файлы для отправки в AI-модели.

## Что делает

- Сканирует папку с проектом
- Собирает содержимое всех файлов
- Разбивает на части по лимиту символов модели
- Копирует содержимое в буфер
- Запускает HTTPS-сервер для браузерного расширения
- Автоматически отправляет контекст в чат DeepSeek

## Быстрый старт

1. Запусти `Code2Prompt.exe`
2. Выбери папку с проектом → **Старт**
3. Нажми **🚀 Запустить сервер**
4. **Важно:** Открой в браузере `https://localhost:9090/project` и нажми **"Продолжить"** (Advanced → Proceed to localhost)
5. Установи расширение из папки `extension-chromium/` (chrome://extensions → Загрузить распакованное)
6. Открой `chat.deepseek.com`
7. Нажми `Ctrl+Enter` — контекст отправится в чат

> **Примечание:** Самоподписанный сертификат генерируется автоматически при первом запуске сервера. Предупреждение браузера — это нормально.

## Требования для сборки

Для сборки автономного приложения (app-image) требуется **Liberica JDK 21 Full** (с JavaFX).

Скачать: https://bell-sw.com/pages/downloads/

Выбрать: Windows, JDK 21, Full

### Задачи Gradle

|---------|------------|
